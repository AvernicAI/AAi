A FEW USEFUL DETAILS

Before you
jump in.

What is AlphaAi?

AlphaAi is the AI desktop workspace by AAi. It brings agent conversations, an IDE, terminals, a browser, skills, and integrations together. The project also includes terminal and web workflows.

Can I use my own models?

Yes. Connect supported providers with your own credentials, or configure a compatible endpoint and model ID. Local endpoints can be used where compatible. Model availability, capabilities, and costs depend on the provider you choose.

Which model routes can I try for free?

The desktop includes keyless presets for Kilo Code, LLM7.io, and OVHcloud. Other presets may require an account, a trial key, or billing. Provider usage and third-party subscriptions follow the provider’s terms.

How does local discovery help with costs?

AlphaAi ranks eligible tools and skills locally before the first primary provider request and loads detailed tool signatures on demand. This helps keep unnecessary tool context out of the request, without adding a separate discovery model call. Savings vary by task, model, and configuration.

Do integrations need setup?

Convio needs an API key. Ultima3D includes its host, and live editor connections need add-ons. Blender MCP, REA, and some Pullstack workflows need the dependencies listed above. You choose which tools to enable.

What control do I have over agent actions?

AlphaAi provides permission controls and tool approvals. Review changes in the workspace and manage the tools available to your sessions. Desktop mouse and keyboard actions are intended for a local interactive Windows session.

Which desktop download is available here?

The Windows x64 development preview is version {{VERSION}}. Windows and the installer display its build name, AAi Dev. The repository contains the broader project and platform build configuration.
